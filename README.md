## 🚀 Lancer le site en local

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Killian0209/Killian0209.github.io.git
   ```
2. Ouvrir le dossier dans **Visual Studio Code**
3. Lancer l'extension **Live Server** (clic droit sur `index.html` → *Open with Live Server*)
4. Le site s'ouvre sur `http://127.0.0.1:5500`
